Privacy Policy - AI Short Generator

Last updated: July 2026

AI Short Generator is a personal, single-user automation tool built and operated by an individual developer. It is not a public product or service offered to other users.

What this application does

This application generates short-form fictional video content (AI-generated horror, mystery, science-fiction, and fantasy stories) and, with the developer's explicit authorization via OAuth, uploads that content to the developer's own TikTok account draft inbox for manual review and publishing by the developer.

Data we access

This application only accesses the TikTok account of the developer, who is also the sole user of the application. It does not access, request, or process data belonging to any other TikTok user or third party.

Data storage

OAuth access tokens and refresh tokens issued by TikTok are stored locally, on the developer's own machine, and are never transmitted to any third-party server or service. No user data is sold, shared, or disclosed to any third party.

Data retention and deletion

Locally stored tokens can be deleted at any time by removing them from the local device. Revoking the application's access via TikTok's own account settings immediately invalidates any stored tokens.

Contact

For any question about this application or this policy, contact the developer directly through the TikTok Developer Portal listing for this application.
